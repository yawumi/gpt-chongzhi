# ChatGPT Plus 充值教程（2026）：微信、支付宝开通与续费，附 Pro / Claude 充值方法

**简体中文** | [English](README.en.md)

想给自己的 ChatGPT 账号开通 Plus，却没有可用的海外信用卡，可以通过支持国内付款方式的自助充值服务完成。**本文演示用微信或支付宝购买充值卡密，再把 Plus 会员充到自己账号的完整过程。**

下面以 V3小店为例，按实际页面说明怎么选商品、填写订单、完成付款、提取卡密，以及如何在充值中心提交充值。第一次操作，按顺序往下做即可。

整个流程可以先记成一条线：

**选择 Plus 商品 → 微信 / 支付宝付款 → 提取卡密 → 验证卡密 → 确认充值账号 → 提交充值 → 查看会员状态。**

本文按 2026 年 10 月 25 日的公开页面核对。价格、库存和可用充值渠道会变化，下单时再确认商品详情。

## 一、ChatGPT Plus 充值前，需要准备什么？

先准备好三样东西：

1. **一个能正常登录的 ChatGPT 账号**：后面要把会员充到这个账号上。先在浏览器中登录，确认邮箱和当前套餐。
2. **一个常用邮箱**：下单时填写，用于订单联系和查询。
3. **微信或支付宝**：在店铺购买卡密时付款使用。

建议用电脑浏览器操作，分别打开店铺和自己的 ChatGPT 账号，后面复制卡密、切换充值页面会方便一些。使用手机时，也可以在浏览器中完成对应步骤。

如果账号已经有 Plus，先看一下到期时间。不同充值渠道对续费的处理不同，选商品时要用到这个信息。

## 二、如何用微信、支付宝下单购买 Plus 充值卡密？

### 第 1 步：打开店铺，选择 ChatGPT Plus 充值商品

打开 [V3小店](https://shop.gpt.ge/)，在商品列表中找到标有「plus充值」的商品。当前有菲卡和 iOS 两种渠道，点进商品详情后，先确认购买的是 **ChatGPT Plus 会员充值**。

两种渠道主要按现有订阅情况选择：

| 充值渠道 | 当前商品说明中的续费条件 |
| --- | --- |
| Plus 菲卡充值 | 已有 Plus 的账号，需要等原订阅到期后再充值。 |
| Plus iOS 充值 | 可以覆盖充值，但原有剩余时间不会叠加。之前通过 iOS 充值的用户，可先看这一款的续费说明。 |

如果只是为一个账号开通一个月，确认商品周期后，购买数量通常选 **1** 即可。商品显示缺货时，等恢复库存后再下单。

### 第 2 步：填写联系邮箱，设置查询密码

在商品页的购买区域填写：

- **联系邮箱**：填一个自己能正常收信的邮箱，后续可以用它查找订单。
- **查询密码**：为这笔订单设置一个取件码，付款后提取卡密时会用到，请自己保存好。
- **人机验证**：输入页面显示的数字验证码。

这里的「查询密码」是店铺订单的取件码，请单独设置。**实际要充值的 ChatGPT 账号，会在后面的充值中心确认。**

### 第 3 步：选择微信或支付宝，确认付款

在「支付方式」中选择 **微信** 或 **支付宝**，然后：

1. 点击「立即购买」。
2. 在「订单确认」窗口核对商品名称、购买数量、实付金额、支付方式和联系邮箱。
3. 确认无误后，点击「确认支付」。
4. 按支付页面提示完成付款。

页面显示二维码时，用对应的微信或支付宝扫码；如果跳转到收银台，就按收银台提示继续。手机端如显示「前往APP支付」，点击后在对应 App 中完成付款。微信付款页如提供「复制支付链接」，也可以复制后发送到自己的微信「文件传输助手」，再打开链接支付。

付款成功后，等待页面返回订单详情，并保存订单编号。如果支付页面没有及时跳转，可以从下一步的订单查询入口找回订单。

## 三、支付成功后，怎么提取充值卡密？

### 第 4 步：输入查询密码，查看卡密和使用说明

进入订单详情后，先确认「支付状态」显示为「已支付」，再找到「卡密信息」区域。

如果页面要求输入密码：

1. 填入刚才下单时设置的**查询密码**。
2. 点击「查询卡密」。
3. 查看显示出来的卡密内容，以及「使用说明（必读）」。
4. 复制并保存充值卡密，记下订单提供的充值地址。

订单编号用于查订单和申请售后，充值卡密用于下一步兑换会员，两个都要保存。

如果已经关闭付款页面，打开[订单查询](https://shop.gpt.ge/order)，输入**订单编号或下单邮箱**，找到对应订单后，再按上面的步骤提取卡密。

**做到这里，完成的是购买卡密；接下来还要把卡密兑换到自己的 ChatGPT 账号。**

## 四、拿到卡密后，如何充值到自己的 ChatGPT 账号？

### 第 5 步：打开充值中心，验证 Plus 卡密

按订单说明打开 [AI 充值中心](https://ai.gpt.ge/)。当前 ChatGPT 充值页面分为三个阶段：**卡密验证、获取 Token、提交充值**。

在「充值卡密」输入框粘贴刚才提取的卡密，点击「验证卡密」。验证通过后，检查页面识别出的充值类型，确认与购买的 Plus 商品一致，再继续。

复制时只取卡密本身，避免把订单编号、使用说明或多余空格一起填入。

### 第 6 步：获取账号信息，填写 JSON Token

页面进入「获取 Token」阶段后，按下面的顺序操作：

1. 在**同一个浏览器**中打开 ChatGPT，登录要充值的账号。如果还没登录，可以点击充值页的「前往 ChatGPT 登陆」。
2. 确认当前登录邮箱就是本次要充值的账号。
3. 回到充值页，点击「前往复制 Token 代码」。
4. 新打开的页面会显示一段 JSON 格式的账号会话信息，将**整个页面的 JSON 内容**完整复制。
5. 回到充值页，把内容粘贴到「JSON Token」输入框，再继续下一步。

这里需要完整的 JSON 内容，保留开头和结尾的大括号。只复制邮箱、截图，或只复制其中一小段，都会导致验证无法通过。如果当前卡密显示了不同的账号信息要求，就按对应输入框的说明填写。

Token / Session JSON 含有账号访问凭证，提交前请确认你信任该充值服务；不要把这段内容发到聊天、截图或公开仓库中。

### 第 7 步：核对充值邮箱，提交充值

进入确认页面后，重点核对**充值邮箱和充值类型**。尤其是浏览器里登录过多个 ChatGPT 账号的情况，要确认这里显示的是你准备开通 Plus 的那个账号。

如果页面提示账号已有会员，并询问是否覆盖充值，先确认自己接受剩余时间的处理方式，再继续。

核对无误后点击「确认充值」，等待页面返回处理结果。如果页面提示需要完成安全验证，按提示在新窗口完成验证，再回到原页面查看结果。

显示「充值处理中」时，继续查看这笔充值的进度。暂时没有结果时，保留原卡密和订单信息，先查询原订单的状态。

### 第 8 步：回到 ChatGPT，确认 Plus 是否到账

充值中心提示成功后，回到自己的 ChatGPT 账号，刷新页面并在账号设置中查看当前套餐。确认账号显示 Plus，再核对订阅状态。

如果充值页面已提示成功，ChatGPT 页面却还没有更新，可以重新登录后再查看。如果充值后超过 30 分钟仍未到账，保留订单号、支付凭证和充值结果，通过店铺客服核查。

到这里，就完成了从微信或支付宝付款，到给自己的账号开通 ChatGPT Plus 的操作。

## 五、ChatGPT Pro 和 Claude Pro 怎么充值？

### ChatGPT Pro 充值与续费

需要充值 Pro 时，回到店铺选择「ChatGPT Pro」商品，先查看当前套餐规格、可售状态和办理方式。部分商品可能需要按详情中的说明办理。

如果购买的是自助充值卡密，付款和提取卡密的方法与前面相同。进入充值中心后，验证卡密并确认识别出的类型是 **Pro**，然后按页面要求填写账号信息、核对邮箱、提交充值。

已有 Plus、准备升级 Pro 的用户，先阅读商品中的升级和剩余订阅处理说明。实际到账套餐与可用额度，在自己的账号中确认。

### Claude Pro 充值与续费

Claude Pro 也需要先购买对应商品并提取卡密，后面的账号填写步骤有所不同：

1. 打开充值中心，切换顶部的「Claude Pro」。
2. 输入购买的 Claude 卡密，点击「验证卡密」。
3. 进入「绑定账号」步骤，点击页面中的「打开 Claude 设置页面，获取 Organization ID」。
4. 登录要充值的 Claude 账号，从账号设置中复制 Organization ID，粘贴回充值页面。
5. 核对后点击「绑定账号」，再点击「提交充值」。
6. 等待处理结果，完成后回到 Claude 账号查看 Pro 订阅状态。

Claude 商品当前说明涉及覆盖续费，已有订阅的用户要先确认剩余时间如何处理。商品缺货时，等待补货后再操作。

## 六、Plus 充值常见问题

### 微信、支付宝已经扣款，为什么 ChatGPT 还没有 Plus？

先看自己操作到了哪一步。店铺付款成功后交付的是充值卡密，**还需要提取卡密，并在充值中心完成账号确认和提交充值**。可以按本文第三、四部分继续操作。

如果已经提交充值，再查看充值中心的处理结果和目标账号的套餐状态。

### ChatGPT Plus 充值多少钱？为什么付款金额略有不同？

菲卡和 iOS 渠道的价格可能不同，打开对应商品即可查看当前售价，核对商品周期和数量后再付款。店铺说明采用港币结算，汇率换算可能使实际扣款与标价有小幅差异，付款前以收银台显示的金额为准。

### Plus 还没到期，可以提前续费吗？

要看购买的渠道。当前菲卡商品要求 Plus 到期后再充值；iOS 商品支持覆盖充值，但剩余时间不会叠加。如果希望用完当前会员时长，可以等到期后再按对应商品说明续费。

### 充值卡密要填在 ChatGPT 的哪里？

本文使用的卡密填写在**订单提供的充值中心**，先点「验证卡密」，再按页面提示绑定要充值的账号。订单编号和查询密码各有用途，都不能代替充值卡密。

### 提示 JSON Token 无效，怎么处理？

先确认同一浏览器里已登录要充值的 ChatGPT 账号，再重新点击「前往复制 Token 代码」，复制最新的完整 JSON 内容。粘贴时保留大括号和全部字段，检查是否漏复制了一部分，或只复制了某个字段的值。

### 查询密码忘了，能用 ChatGPT 密码提取卡密吗？

查询密码是你在店铺下单时单独设置的取件码。请先检查自己保存的订单信息；仍无法找回时，准备好订单号和支付凭证，请店铺客服协助核查。

### 充值需要把 ChatGPT 密码发给客服吗？

本文演示的流程中，登录 ChatGPT 由你在自己的浏览器里完成，店铺的查询密码也由你单独设置。充值中心会按卡密类型要求填写账号信息，标准流程中的 Token 属于敏感访问凭证，使用前请阅读第四部分的说明。

### Plus 充值和 AI API 余额充值怎么区分？

如果目的是在自己的 ChatGPT 账号中开通会员，选择对应的 Plus 或 Pro 会员商品。如果目的是给程序、网站或客户端调用模型，店内另有中转 API 余额充值商品，兑换到 gpt.ge API 平台钱包。下单时先确认自己需要的是哪一种。

### 卡密可以买来以后再用吗？

按实际使用时间购买，收到后尽快充值并核验结果。店铺提示 Plus、Pro 等卡密尽量不要囤放超过 7 天，部分商品可能有更严格的要求。

### 微信或支付宝付款后，能开发票吗？

店铺当前说明微信和 USD 支付会自动开具海外 Invoice，不支持开具中国大陆发票。有报销需求时，先确认单位接受的凭证类型，以及所选支付渠道的开票说明。

### 充值失败或者掉订阅，怎样联系售后？

保留订单号、付款记录和错误提示，通过[店铺客服](https://shop.gpt.ge/contact)说明问题发生在付款、提取卡密，还是提交充值阶段。截图时遮住完整卡密和 Token，方便客服核查订单，也避免公开账号凭证。

不同商品的售后期限和处理范围不同，申请前查看购买时的商品说明。下单、订单查询等操作问题，也可以查阅店铺的[购买帮助](https://shop.gpt.ge/help)。
